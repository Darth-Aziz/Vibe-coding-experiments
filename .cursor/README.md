# `.cursor/` — AI and sprint tooling

This directory keeps **Cursor** rules, **agent personas**, **skills**, and **sprint artifacts** aligned with Tasheel delivery. It is not required to **run** the app; the runnable product is **`tasheel/`**.

| Folder | Contents |
|--------|----------|
| **`rules/`** | Always-on workspace rules (`global.mdc`, orchestrator routing, etc.). |
| **`agents/`** | Markdown prompts per role (Sultan, Yaser, orchestrator, …). |
| **`skills/`** | Reusable skill docs (Tasheel architecture, design system, team OS, …). |
| **`context/`** | Rubrics, project reference, community skill maps. |
| **`sprint/`** | Per-sprint outputs: requirements, reviews, scorecards, dashboards. |
| **`agent-memory/`** | Institutional notes from completed sprints (when used). |

**Human entry points:** repository root [`AGENTS.md`](../AGENTS.md) and [`docs/README.md`](../docs/README.md).
